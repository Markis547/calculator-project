# Отчет по лабораторной работе: Командная разработка в Git


## 1. Состав команды и роли
В связи с индивидуальным выполнением работы, была произведена полная имитация командной разработки. Все роли распределены на одного исполнителя:
- Team Lead (Тимлид): Управление репозиторием, код-ревью, слияние веток.
- Разработчик №1: Создание базовых функций калькулятора.
- Разработчик №2: Создание расширенных функций калькулятора.

## 2. Ход выполнения работы
1. Шаг 1: Создан публичный репозиторий на GitHub, настроен файл `.gitignore`. Проект клонирован на локальный компьютер.
2. Шаг 2: Настроены глобальные параметры Git, создана и отправлена на сервер ветка `develop` (Рисунок 3).
3. Шаг 3: В ветке `feature/basic-operations` написан код базовых операций. Произведен коммит и отправка на сервер (Рисунок 4).
4. Шаг 4: В интерфейсе GitHub создан Pull Request. От имени Тимлида проведено код-ревью, оставлен комментарий к функции деления и выполнено слияние в `develop` (Рисунок 5).
5. Шаг 5: Создана ветка `feature/advanced-operations`, куда добавлен код расширенных функций. При попытке слияния с обновленной веткой `develop` был успешно смоделирован конфликт в файле `calculator.py`. Конфликт разрешен вручную, маркеры удалены, объединенный код отправлен на GitHub (Рисунок 6).
6. Шаг 6: Финальный код стянут в локальную ветку `develop`, оформлены отчетные файлы.

## 3. Вывод
В ходе работы были освоены навыки работы с ветвлением Git, имитации ролей внутри команды, проведения код-ревью через Pull Request, а также ручного разрешения конфликтов слияния (Merge Conflicts).
